# CF Roundups

Поиск товаров Creative Fabrica (Algolia) → фильтры → выбор → подборки → CSV для блога.
Без ИИ, без Google Sheets, без фоновых задач: запросы выполняются только по кнопке «Найти».

## Запуск (по шагам)
1. Установите Python 3.10+ (python.org), если его нет.
2. Откройте командную строку в этой папке.
3. `pip install -r requirements.txt`
4. `streamlit run app.py` — приложение откроется в браузере.

## Первый запуск
1. В боковой панели введите **Algolia App ID** и **Search key**.
   Они есть в вашем прежнем проекте: файл `cf_core.py`, строки `ALGOLIA_APP_ID` и `ALGOLIA_API_KEY`.
   Либо положите их в `.streamlit/secrets.toml` (пример рядом) и не публикуйте этот файл.
2. Откройте вкладку **«Диагностика»** и нажмите кнопку проверки. Она покажет, принимает ли Algolia запросы,
   работает ли постраничная загрузка и какие поля есть у товара (рейтинг, отзывы, описание — если они есть).
   Результат (таблицу полей) можно прислать разработчику для донастройки.

## Как пользоваться
1. **Поиск**: запросы по одному в строке (фраза в кавычках = точное совпадение), один тип товаров
   (категории не смешиваются), категории внутри типа, цена, сколько товаров, сортировка, доп. фильтры.
2. Отметьте товары галочками (или «Выбрать все»). Выбор не теряется при новых поисках.
3. «Добавить выбранные в подборку» → вкладка **Подборки**: название статьи, категория, вступление, CTA,
   порядок (номера), удаление, правка названия/описания → «Применить». Можно вести несколько подборок.
4. **Экспорт**: проверка → «Скачать CSV».

## Формат CSV (из roundups-template.csv)
Столбцы строго: `article_title, article_category, article_intro, item_title, item_description,
item_image_url, item_affiliate_url, cta_text`. Одна строка = один товар. `article_title` повторяется в каждой
строке подборки, `article_category` и `article_intro` — только в первой. `cta_text` по умолчанию в первой строке
(можно задать и для любой строки). Запятая, UTF-8 без BOM, переводы строк LF. Тест сверяет экспорт с шаблоном
побайтно.

## Что подтверждено, а что нет
- Из данных берутся: название, ссылка, картинка, цена, бесплатный/платный, популярность, дата, тип, категории, теги.
- Рейтинг, число отзывов, описание и формат файла как отдельные поля **не подтверждены**. Если «Диагностика»
  их покажет, укажите имена полей в «Настройки → Дополнительно», и они появятся. Иначе их нет, и ничего не подставляется.
- Формат файла (SVG, PNG…) в данных есть только словами в названии/тегах; отдельного фильтра нет.
- «Популярность» как сортировка считается по найденным товарам; пометка «приближение» означает, что это не
  глобальный топ каталога. Точная сортировка возможна, если указать индекс сортировки по популярности.
- `item_description` берётся из API, если задано поле описания; иначе пусто (правится вручную). Ничего не выдумывается.

## Партнёрская ссылка
Без образца ссылки в CSV попадают обычные URL товаров. Чтобы ID добавлялся автоматически, вставьте в настройках
один образец вашей партнёрской ссылки: формат выводится из него и проверяется. Угадывание формата отключено.

## Доступ и ограничения
- Запросы честные: свой User-Agent, без подмены Referer/Origin. При 401/403 приложение останавливается с понятным
  сообщением и ничего не обходит.
- Результаты кешируются на час. Не запускайте поиск массово: условия Creative Fabrica запрещают скрейпинг.

## Если ошибка 403
Приложение показывает ответ Algolia дословно. Причины и порядок действий:
1. Ключ устарел или введён с ошибкой (ключи на сайте могут меняться): возьмите свежие App ID и Search key
   из браузера (подсказка «Где взять актуальный ключ» в боковой панели) и вставьте заново.
2. Если свежий ключ тоже даёт 403, он, вероятно, ограничен сайтом (по домену/IP). Приложение этого не обходит:
   подмена Referer/Origin сознательно не используется.
3. Полезная проверка: работает ли сейчас ваш прежний дашборд с тем же ключом? Если да, а новый выдаёт 403,
   прежний дашборд проходит благодаря подмене заголовков, то есть ограничение действительно есть.

форматы, прогон интерфейса).
